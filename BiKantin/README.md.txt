# BI-KANTIN — Desktop Application

BI-KANTIN is a desktop-based canteen management application developed using Java and NetBeans IDE. This project was created as part of a software development learning project, with the goal of applying programming concepts to a canteen management system.

## About the Project

BI-KANTIN is designed as a desktop application for a canteen environment. The project serves as a practical implementation of Java programming and desktop application development.

## Tech Stack

- **Programming Language:** Java
- **IDE:** NetBeans
- **Application Type:** Desktop Application

## Getting Started

### Prerequisites

Before running the application, make sure you have:

- Java Development Kit (JDK)
- NetBeans IDE
- The project source code

### Installation

1. Clone or download this repository.
2. Open NetBeans IDE.
3. Select **File → Open Project**.
4. Navigate to the downloaded `BiKantin` project folder.
5. Wait for NetBeans to load the project.
6. Run the application using the **Run Project** button.

*Note: Additional configuration may be required depending on the project's existing setup.*

## Project Structure

The project contains the source code and configuration files required to develop and run the desktop application.
